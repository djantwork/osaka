# Asteroids

A classic Asteroids clone built with HTML5 canvas. Fly the ship, dodge rocks, shoot asteroids and UFOs, and survive increasingly difficult waves.

## Features
- Ship rotation and thrust with smooth physics and screen wrap
- Bullet shooting, asteroid destruction with splitting, and score tracking
- Particle effects for thrust and explosions
- UFO enemies that enter the playfield and fire at the player
- Lives system with invulnerability on respawn
- Progressive difficulty: more asteroids each level, faster UFO cadence

## Controls
- **Left / Right**: rotate
- **Up**: thrust
- **Space**: fire (also starts the game)

## Running the game
Open `index.html` in a modern browser. No build step or dependencies are required.
